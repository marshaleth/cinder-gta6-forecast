# GTA VI Launch-Day Twitch Viewer Forecast

Quantile forecaster for make.fun's "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty, $250 in USDC. Given the day's first-hour viewership and 40+ comparable console-launch Twitch curves, it predicts hours 2-24 of the GTA VI Twitch category with calibrated 5/25/50/75/95% quantiles: robust log-ratio distributions (median/MAD, sigma-capped) per hour, lightly smoothed, spread widened for a bigger title.
